## 📋 Overview

**Researcher Outreach Pro** is a self-contained web application that helps researchers, academic teams, and research-driven organizations discover relevant researchers, locate verifiable contact information, and manage personalized outreach campaigns — all from a single workflow.

It is especially suited to research-intensive fields such as **Bioinformatics, Genomics, Computational Biology, and Stem Cell Research**.

Rather than relying on a single database or manual searching across dozens of sites, the system cross-references multiple scholarly sources and applies a verification layer before any researcher or email is considered outreach-ready.

**Find the right researchers → verify their contact information → personalize the outreach → track the response.**

---

## 🎯 The Problem

Academic outreach is usually slow and fragmented:

- Finding researchers who genuinely work on a specific topic
- Searching across many scientific databases and publication platforms
- Locating a researcher's *own* email rather than a co-author's
- Verifying that an email truly belongs to the intended person
- Personalizing messages without writing each one from scratch
- Tracking replies, bounces, and records that need manual review

Researcher Outreach Pro consolidates these steps into one focused workflow.

---

## ⭐ What It Does

- **Discovers researchers** relevant to a given topic across major scholarly sources
- **Locates and verifies contact information**, favoring publicly published evidence over guesswork, with uncertain matches routed to manual review instead of being auto-accepted
- **Avoids misattribution** between co-authors when extracting contact details from shared publications
- **Personalizes and schedules outreach** through a template-based editor with tracking
- **Monitors replies and bounces** and classifies responses automatically
- **Surfaces everything on a dashboard** — discovery rates, contact status, reply/bounce stats, and records needing review
- **Runs key steps on a schedule**, so discovery and outreach don't have to be fully manual

The overall idea: go from a research topic → a vetted list of relevant researchers → a tracked, personalized outreach campaign, with a human checkpoint wherever confidence is low.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express, SQLite
- **Frontend:** Vanilla HTML/CSS/JavaScript (single-page application)
- **Supporting libraries:** rich-text editing, dashboard charting, scheduled jobs, SMTP delivery, mailbox monitoring

```bash
npm install
npm start
```

## 🔒 Privacy & Responsible Use

- No tracking pixels in outgoing emails
- Contact addresses are never generated by guessing name + domain combinations
- Only publicly available sources are used
- Credentials and API keys stay in application settings, never hardcoded
- Uncertain records go through manual review before any outreach

**Intended use** includes research collaboration, internship and volunteer inquiries, computational collaboration, academic networking, and sharing relevant research. It is **not** intended for spam, unsolicited commercial marketing, or any activity that violates applicable anti-spam or communications regulations. Users are responsible for ensuring their use complies with applicable laws and policies.
